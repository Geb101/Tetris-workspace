# Вопросы к заказчику

1. На каком языке должна быть написана документация?
2. Какой формат и способ передачи финальной версии предпочтителен?
3. Есть ли ограничения по количеству страниц или символов?
4. Нужно ли объяснять управление с помощью геймпада?
5. Можно ли использовать друзей или родственников для проверки документации?
6. Можно ли использовать скриншоты, схемы и записи геймплея?

## Зафиксированные решения

Финальная версия документации будет передана через Google Docs.

Git используется как рабочее пространство для записок и истории подготовки, а не как основной формат передачи результата.
