# Конечные цели документации

После прочтения документации пользователь должен:

1. Уметь самостоятельно начать игру в «Тетрис».
2. Понимать основные концепции игры.
3. Уметь объяснить правила своими словами.
4. Продемонстрировать базовое владение игрой.

Логика прогрессии: обучение → проверка понимания → применение → совершенствование.
