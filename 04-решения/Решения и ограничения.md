# Решения и ограничения

## Формат передачи

Финальная документация передаётся через Google Docs.

## Роль Git

Git используется как рабочий архив для записок, решений, результатов проверок и истории изменений.

## Буфер обмена

`Test-doc.md` не является финальным документом. Это буфер обмена, поэтому он не переносится в новую структуру и не включается в Git.

## Рабочий процесс

1. Сначала фиксируются требования и конечные цели.
2. Затем определяется аудитория и структура документации.
3. После этого материал проверяется на читателе и критиком.
4. OpenScreen используется для записи игровых действий и подготовки визуальных материалов.
5. BrowserSkill используется для проверки структуры, отображения и доступности документации в Google Docs.
6. Изменения и причины решений сохраняются в рабочих записках.
