# Tetris Documentation — рабочие материалы

Этот репозиторий содержит рабочие записки по подготовке технической документации к игре «Тетрис» для читателя, который никогда не играл в неё.

Финальная версия документации передаётся через Google Docs. Ссылка на этот репозиторий добавлена в сам документ как демонстрация процесса подготовки: требований, проверок, решений и истории изменений.

## Что здесь находится

Рабочий процесс, а не финальный документ:

- требования и цели документации;
- описание целевой аудитории;
- использованный стек инструментов;
- результаты проверок на реальных читателях;
- результаты проверки ИИ-критиком;
- журнал решений и ограничений;
- лог технических действий;
- инструкция по верстке итогового документа;
- промпты, использованные для проверки.

## Структура

- `01-планирование/` — задачи, цели и требования к результату.
- `02-исследование/` — аудитория, ограничения и выбранный стек.
- `03-проверка/` — результаты проверки на читателе и критиком, анализ верстки.
- `04-решения/` — общий процесс, принятые решения, история изменений, лог действий.
- `05-промпты/` — промпты, использованные для проверки документации.
- `06-финальная-передача/` — инструкция по верстке и сведения о передаче документа.

## Процесс подготовки

Общая схема описана в `04-решения/Общий процесс.md`:

```text
требования → текст → проверка критиком → проверка на читателе →
правки → перевод → верстка → валидация → тест на новичке → передача
```

## Использованный стек

- GPT-5.6 Luna — подготовка и редактирование текста.
- Antigravity — выполнение верстки документа.
- Google Docs MCP — программный доступ к Google Docs.
- OpenScreen — запись геймплея для визуальных материалов.
- BrowserSkill — браузерная валидация итогового документа.
- Google Docs — финальная передача документации.

## Что не включено

- Буферные файлы и промежуточные черновики.
- Финальный текст документации (он живёт в Google Docs).
- Секреты, токены и OAuth-данные.
- Локальные настройки Obsidian и служебные файлы.

## Статус

- Глава «Знакомство с игрой» — написана, проверена, переведена.
- Практическая глава — написана, верстка в процессе.
- Тест на неопытном читателе — следующий шаг.
