# Финальная передача

Финальная версия документации будет подготовлена и передана через Google Docs.

Git-репозиторий используется для рабочих записок и демонстрации процесса подготовки. Он не заменяет ссылку на финальный документ.

Перед передачей нужно проверить:

- актуальность текста;
- наличие всех необходимых иллюстраций и примеров;
- результаты проверки на читателе;
- результаты проверки критиком;
- отсутствие буферных и случайных файлов.
